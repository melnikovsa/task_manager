# 📋 Task Management System API

Веб-приложение (REST API) для управления задачами и совместной работы, разработанное на **Django** и **Django REST Framework**. Проект оформлен как полноценный Python-пакет и полностью контейнеризирован.

---

## ✨ Функциональные возможности

- **Пользователи**: Аутентификация и авторизация на базе **JWT-токенов** (SimpleJWT). Доступна открытая регистрация.
- **Задачи (CRUD)**: Создание, просмотр, редактирование и удаление задач. Автором автоматически становится создатель задачи.
- **Назначение исполнителей**: Возможность делегировать задачу любому зарегистрированному пользователю.
- **Управление статусом**: Быстрое переключение состояния выполнения задачи (Выполнено / Не выполнено).
- **Комментарии**: Возможность комментировать любую задачу для обсуждения деталей.
- **Безопасность**: Изменять или удалять задачу могут только её автор либо назначенный исполнитель.
- **Документация**: Автоматически генерируемая интерактивная документация **Swagger** и **ReDoc**.

---

## 🛠 Технологический стек

- **Backend**: Python 3.10+, Django 4.2, Django REST Framework
- **Аутентификация**: Django REST Framework SimpleJWT
- **СУБД**: PostgreSQL 15
- **Сборка пакета**: Setuptools (`setup.py`)
- **Оркестрация**: Docker, Docker Compose
- **Документация**: drf-yasg (Swagger UI / ReDoc)

## 🚀 Вариант 1. Быстрый запуск через Docker (Рекомендуемый)

Для этого варианта на вашем компьютере должны быть установлены Docker и Docker Compose. **Вам не потребуется устанавливать Python или PostgreSQL локально.**

### 1. Клонирование репозитория
```bash
git clone https://github.com/melnikovsa/task_manager
cd task-manager
```

### 2. Сборка и запуск контейнеров
Выполните команду в корневой директории проекта:
```bash
docker-compose up --build
```
*Что произойдет автоматически:*
- Поднимется контейнер с базой данных PostgreSQL и выполнится проверка его готовности.
- Сберется образ Django-приложения (зависимости установятся через `setup.py`).
- Применятся все миграции базы данных.
- Сервер станет доступен по адресу: **`http://localhost:8000/`**

### 3. Создание суперпользователя (для доступа в админку)
В новом окне терминала выполните команду:
```bash
docker-compose exec web python manage.py createsuperuser
```

## 💻 Вариант 2. Локальный запуск (Без Docker)

Для локального запуска вам потребуется установленный **Python 3.10+** и запущенный сервер **PostgreSQL** (параметры подключения настраиваются через переменные окружения в `task_manager/settings.py` или используются дефолтные: `localhost:5432`, БД `task_manager_db`).

### 1. Настройка виртуального окружения
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
venv\Scripts\activate     # Для Windows
```

### 2. Установка проекта в редактируемом режиме
```bash
pip install -e .
```

### 3. База данных и миграции
Убедитесь, что в PostgreSQL создана пустая база данных `task_manager_db`. Затем выполните:
Создание миграций при запуске через докер
```bash
docker-compose run --rm web python manage.py makemigrations users
docker-compose run --rm web python manage.py makemigrations tasks

```

```bash
python manage.py migrate
python manage.py createsuperuser
```

### 4. Запуск сервера разработки
```bash
python manage.py runserver
```
Сервер будет доступен по адресу: **`http://127.0.0`**

## 📚 Документация API

После запуска сервера интерактивная документация доступна по адресам:
- 🔐 **Swagger UI**: [http://localhost:8000/swagger/](http://localhost:8000/swagger/)
- 📖 **ReDoc**: [http://localhost:8000/redoc/](http://localhost:8000/redoc/)

> **Примечание по авторизации:** Чтобы выполнять запросы к защищенным эндпоинтам задач и комментариев, сначала отправьте POST-запрос на `/api/token/` с вашими данными. Полученный `access`-токен передавайте в заголовках запросов:
> `Authorization: Bearer <ваш_access_токен>`

## 🧪 Запуск тестов

В проекте реализовано полное покрытие ключевой функциональности юнит-тестами (регистрация, JWT-логика, CRUD задач, права доступа, добавление комментариев).

- **Запуск тестов в Docker:**
  ```bash
  docker-compose exec web python manage.py test
  ```
- **Запуск тестов локально:**
  ```bash
  python manage.py test
  ```

## 🔍 Проверка качества кода (PEP 8)

В проекте используется линтер **Flake8** для контроля качества кода.

### 1. Установка линтера (локально)
Если проект устанавливался локально, накатите зависимости для разработки:
```bash
pip install -e .[dev]
```

### 2. Запуск проверки
Запустите команду в корне проекта:
- **Локально:**
  ```bash
  flake8 .
  ```
- **Через Docker Compose:**
  ```bash
  docker-compose exec web flake8 .
  ```
Линтер автоматически просканирует весь ваш код (исключая миграции и системные файлы) и покажет отчёт, если где-то нарушены отступы, отсутствуют пустые строки или превышена длина строки.
